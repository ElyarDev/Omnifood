# 🍴 Omnifood

A modern, responsive, and user-friendly **food subscription website** built with **HTML, CSS, and JavaScript**.

Omnifood is a fictional AI-powered food subscription service that helps users discover personalized meals based on their tastes and nutritional needs.

### ✨ Features

* 📱 Fully responsive design
* 🏠 Modern hero section with call-to-action buttons
* 🥗 Meals and diet options
* ⚙️ How It Works section
* ⭐ Customer testimonials
* 🖼️ Food image gallery
* 💰 Starter and Complete pricing plans
* 📝 User signup form
* 📱 Responsive mobile navigation
* 🔗 Smooth scrolling navigation
* 🎨 Clean and modern UI design

### 🛠️ Built With

* **HTML5** — Semantic page structure
* **CSS3** — Styling, layout, and responsive design
* **JavaScript** — Interactive functionality
* **Font Awesome** — Icons
* **Responsive Web Design** — Optimized for different screen sizes
