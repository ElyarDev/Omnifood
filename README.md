# 🍴 Omnifood

A modern and responsive food subscription website built with **HTML, CSS, and JavaScript**.

### ✨ Features

* Responsive design
* Hero section
* How it works section
* Meals & diets
* Customer testimonials
* Food gallery
* Pricing plans
* Call to action & signup form
* Mobile navigation
* Smooth scrolling

### 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Responsive Web Design
