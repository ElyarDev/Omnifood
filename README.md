# 🍽️ OmniFood — AI-Powered Healthy Meal Delivery

**OmniFood** is a modern, responsive landing page for an AI-powered healthy meal delivery service.

The website is designed to provide users with personalized meals based on their dietary preferences and lifestyle, while presenting the service through a clean, modern, and engaging user interface.

🔗 **Live Demo:** [View Website](https://elyardev.github.io/Omnifood/)

---

## ✨ Features

- 📱 **Fully Responsive** — Optimized for mobile, tablet, and desktop screens
- 🍱 **Meal Showcase** — Display different meals with nutritional information
- 🤖 **AI-Powered Concept** — Modern UI built around personalized meal recommendations
- ⭐ **Customer Testimonials** — Dedicated customer reviews section
- 💰 **Pricing Plans** — Clear and responsive pricing cards
- 🖼️ **Food Gallery** — Visual gallery showcasing different meals
- 📊 **Service Statistics** — Highlighting important business metrics
- 📩 **Newsletter Section** — Email subscription UI
- 🧭 **Responsive Navigation** — Mobile-friendly navigation menu
- 🎨 **Modern UI** — Clean typography, spacing, colors, and visual hierarchy
- ⚡ **Smooth Interactions** — Hover effects, transitions, and interactive elements

## 📸 Website Sections

The website includes several sections designed to create a complete modern landing page:

### 🏠 Hero Section
A strong introductory section that presents the OmniFood service and encourages users to explore the platform.

### 🍴 Featured Meals
Showcases popular meals along with information such as calories, ratings, and dietary properties.

### 📅 How It Works
Explains the process of receiving personalized meals through a simple step-by-step experience.

### ❤️ Testimonials
Displays feedback from customers to build trust and credibility.

### 📱 App Experience
Promotes the OmniFood mobile experience with dedicated visuals and content.

### 🖼️ Food Gallery
A responsive image gallery designed to showcase different meals and food experiences.

### 💳 Pricing
Provides multiple subscription options with clear pricing and included features.

### 📩 Call To Action
Encourages visitors to start using the service and subscribe to a meal plan.
